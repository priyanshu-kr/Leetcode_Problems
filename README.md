## 💡 Solution Approach

For each problem, I try to focus on:

1. Understanding the problem and constraints
2. Identifying the appropriate data structure or algorithm
3. Developing a straightforward solution
4. Optimizing the solution where necessary
5. Analyzing **time and space complexity**
6. Writing clean and readable Python code

## ⏱️ Complexity Analysis

Solutions include complexity analysis whenever appropriate.

For example:


The goal is not just to solve a problem, but to understand **why the solution works and how efficiently it works**.
